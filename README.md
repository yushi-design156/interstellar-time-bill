# 星际穿越时间账单 · Interstellar Time Bill

一颗克尔黑洞旁边，你在某颗星球上待一小时，地球上过去了多少年？
拖动质量、自转、轨道半径，左边那团光会跟着变，账单会跟着变——**没有一个是写死的数字**。

作者：**yushi** · 山东工艺美术学院 产品设计

## 一、它算的是什么

赤道面顺行圆轨道上的时间膨胀（G = c = 1，M 归一化为 1）：

```
dt/dτ = 1 / √(1 − 3M/r + 2a·M^1.5 / r^1.5)
```

直接照抄这个式子，当 r 逼近视界时会出现灾难性抵消。代码里做了变量替换
`x = √(1/r)`，把被开方数改写成

```
f(x) = (x − 1)²(2x + 1) + 2(a − 1)x³
```

这样 `f` 恒非负、在 `x = 1`（视界）处平滑为零，浮点上也稳。

三个半径都是算出来的，不是查表：

| 量 | 公式 | 检验 |
|---|---|---|
| 视界 | `r₊ = M + √(M² − a²)` | a=0 → 2M，a=1 → 1M |
| 光子圆轨道 | `r_ph = 2M{1 + cos[⅔·arccos(∓a/M)]}` | a=0 → 3M，a=1 → 1M |
| ISCO | `r_isco = M(3 + z₂ − √[(3−z₁)(3+z₁+2z₂)])` | a=0 → 6M |

`scripts/test-physics.mjs` 有 11 条断言守这些端点，跑 `node scripts/test-physics.mjs` 全绿才算数。

## 二、关于电影，一个不肯让步的结论

米勒行星「1 小时 = 7 年」，反解出来的半径是 **r = 1.0000188 M**，倍率 61,362。
在 a/M = 1 − 1e−14 的极端自转下，**稳定圆轨道的上限只有 1 小时 ≈ 3.85 年**——
再往里需要半径比 ISCO 更靠内 1.9×10⁻⁵ M，那里没有稳定的圆轨道。

也就是说：电影为了把 7 年这个数字做出来，把行星放在了物理上待不住的地方。

作品里没有偷偷改参数去圆这个数。它把这句话直接印在账单上：

> 半径在 ISCO 内侧。这个倍数算得出来，但那儿没有稳定圆轨道
> —— 只有电影能让行星停在这儿。

## 三、画面怎么来的

画面不是贴图，是**在天空着色器里逐像素解透镜方程**：

- 看到 θ 方向的光，真实来自 `b = θ − θ_E²/θ`（点质量薄透镜的**反解**）。
  用正解会把盘的远侧摊成一个盖住半张脸的壳；反解才让远侧的盘贴着阴影拱起来，
  近侧的盘横在阴影前面——就是 Gargantua 那个「眼睛」。
- 每条偏折光线都和赤道面 `y = 0` 求交，命中 `[uIn, uOut]` 才着色。
  盘的位置没有一处是手摆的。
- 盘的亮度带多普勒：`β = 0.50 + 0.46·a/M`，迎面一侧压亮、背面压暗偏红。
- 光子环由 `θ_E` 直接画，视界阴影角取几何量 `asin(r_ph / d)`，相机推拉时星光的弯曲程度与黑洞视觉尺寸一起变。

`scripts/preview.py` 是这套着色器的 numpy 逐行复刻（离线出图），
改预览里的常数等于改 `src/scene.js` 的常数。

## 四、跑起来

```bash
node server.mjs        # 静态托管 + /api/ops 真实探测 + /api/narrate 本地模型写旁白
open http://localhost:8787
```

`server.mjs` 会打印本机 LAN 地址，手机连同一 Wi-Fi 就能看竖屏版。

没有服务也能开：直接双击 `index.html`（`file://` 下作战台会显示「需要本地服务」，
探测不到就不探测，不编数据）。

URL 参数：`?q=low` 低功耗档（软件渲染的机器用），`?still=1` 渲 3 帧后定帧（截图 / OG 图用）。

## 五、作战台

`/api/ops` 每秒探一次三路本机 AI，前端只显示探到什么：

- **Ollama** `:11434` — 已装模型清单、是否有加载中的
- **Dify** `:80` — 容器数、是否已完成 `/install` 初始化
- **Xinference** `:9997` — 是否应答
- **Hermes** — 读 `logs/agent.jsonl` 这条真实调用账本的最后一条，不写死

旁白按钮会真的调本地模型，把这次调用记进同一本账。
